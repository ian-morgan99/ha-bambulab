## Print Failure Detection

| Sensor              | Notes                                                      |
| ------------------- | ---------------------------------------------------------- |
| Spaghetti Detection Alert | Binary sensor that indicates potential print failure detected |

The spaghetti detection system analyzes chamber images on each layer change to detect potential print failures including:
- Spaghetti (thin, chaotic filament structures)
- Detached prints (loss of bed adhesion)
- Mid-air extrusion

**How it works:**
- Converts images to edge maps using edge detection algorithms
- Compares edge density between current frame and a rolling baseline
- Detects sudden non-rigid growth patterns that indicate failure
- Updates baseline every 5 layers to adapt to normal print growth
- Provides a binary sensor and device trigger for automation

**Configuration:**
- Use the "Spaghetti Detection" switch to enable/disable the feature
- The feature requires camera images to be enabled
- **Configurable Thresholds** (available as number entities):
  - **Edge Density Threshold** (0.05-0.50, default 0.15): Percentage increase in edge density from baseline to trigger alert
  - **Sudden Growth Threshold** (0.10-0.50, default 0.25): Percentage frame-to-frame increase to trigger alert
  - **Baseline Update Interval** (1-20 layers, default 5): How often to update the baseline image
  - **Alert Cooldown** (1-10 layers, default 3): Number of layers between alerts to reduce false positives

**Tuning Tips:**
- Increase edge density threshold (e.g., 0.20-0.25) if you get false positives on complex prints
- Decrease edge density threshold (e.g., 0.10-0.12) for faster detection of obvious failures
- Increase cooldown layers if you get repeated alerts for the same issue
- Adjust baseline interval based on print complexity (longer for organic shapes)

**Limitations:**
- Won't detect minor under-extrusion
- Won't detect subtle layer shifts
- Requires good camera visibility of the print
- May have false positives on prints with complex organic structures
